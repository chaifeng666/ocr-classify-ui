# OCR 小工具課程教材包

主計人員生成式 AI 實作課程「用生成式 AI 產製本地 OCR 小工具」的案例教材。所有內容均為練習用假資料，機關名稱以 OOO單位表示。

**一次下載全部：[OCR小工具課程_教材包.zip](OCR小工具課程_教材包.zip)**（約 21 MB）

| # | 檔案 | 內容 |
| --- | --- | --- |
| 1 | [簡報](1_簡報_生成式AI產製本地OCR小工具.pptx) | 18 頁，套用主計總處簡報模板；STEP 0～6 每頁附示範提示詞與實際操作畫面，附講者備註 |
| 2 | [Prompt 提示詞集](2_Prompt_提示詞集.docx) | STEP 0～6 示範提示詞（與簡報同順序）＋ 6 段整合 prompt ＋ 37 段歷程原文 |
| 3 | [素材包](3_素材包_練習用假資料.zip) | 4 張假領據、3 張假發票、受款人 XML 欄位說明 |
| 4 | [成果檔](4_成果檔_工具與匯出範例.zip) | ocr.html、**兩個離線版**（OCR-offline.zip、OCR-classify-offline.zip，解壓後雙擊 start-windows.bat，完全不需連網）、匯出範例、SBOM、參考答案 |
| 5 | [題目檔](5_題目檔_半成品與規範.docx) | **【實作規範】**＋ A／B／C 三組半成品與題目 |
